Linux & Git Cheat Sheet

- \ls -la` : Lists all files and directories in the current folder, including hidden ones, with detailed information.`
- \cd ..` : Changes the current working directory to the parent directory (moves up one level).`
- \pwd` : Prints the absolute path of the current working directory.`
- \mkdir cheat_sheet` : Creates a new directory named "cheat_sheet" in the current path.`
- \rm -rf folder_name` : Forcefully and recursively removes a directory and all of its contents.`
